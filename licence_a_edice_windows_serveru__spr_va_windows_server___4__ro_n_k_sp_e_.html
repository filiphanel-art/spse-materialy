Licence a edice Windows Serveru (Správa Windows Server - 4. ročník SPŠE)

Operační systémy a počítačové sítě

Mgr. Filip Hanel

Úvod do licencování Windows Serveru

  • Při návrhu infrastruktury musíme rozlišovat tři základní pilíře: edici systému, licenci serveru a přístupové licence CAL.
  • Edice Standard a Datacenter sdílejí stejný základ systému a většinu běžných serverových rolí.
  • Pro výuku správy domény obvykle plně postačuje edice Standard.

Srovnání: Standard vs. Datacenter

  • Standard: Určen pro fyzická nebo málo virtualizovaná prostředí, poskytuje právo na 2 virtuální OSE na licenci.
  • Datacenter: Určen pro vysoce virtualizovanou infrastrukturu, poskytuje neomezený počet OSE/VM na licencovaném serveru.
  • Obě edice obsahují AD DS, DNS, DHCP, IIS, Hyper-V, WSUS či Failover Clustering.
  • Datacenter navíc přidává funkce jako Storage Spaces Direct, Network Controller nebo Automatic VM Activation (AVMA).

Model Core-based licencování

  • Windows Server Standard a Datacenter se nelicencují podle počtu instalací, ale podle počtu fyzických jader v serveru.
  • Platí licenční minimum: alespoň 8 licencí na každý fyzický procesor (CPU).
  • Zároveň platí minimum: alespoň 16 licencí na jeden fyzický server.
  • Zjednodušený výpočet: max(skutečný počet fyzických jader, 8 × počet procesorů, 16).

Klientské přístupové licence (CAL)

  • CAL (Client Access License) představuje právo uživatele nebo zařízení přistupovat ke službám serveru.
  • User CAL: Jeden uživatel může přistupovat z libovolného počtu zařízení (vhodné pro učitele s více přístroji).
  • Device CAL: Jedno zařízení mohou používat různí uživatelé (vhodné pro sdílené PC učebny).
  • Vzdálená plocha vyžaduje doplňkovou RDS CAL, která základní CAL nenahrazuje, pouze ji doplňuje.

Verze Windows Serveru (2019-2025)

  • Windows Server 2019: Mainstream podpora skončila v lednu 2024, rozšířená běží do ledna 2029. Vhodné pro migrační scénáře.
  • Windows Server 2022: Mainstream podpora končí v říjnu 2026. Přinesl TLS 1.3, Secured-core a SMB šifrování.
  • Windows Server 2025: Aktuální LTSC verze pro nové laboratoře. Přináší winget, bezpečnější SMB, on-prem SMB over QUIC a LDAP signing.

Nastavení školní laboratoře

  • Doporučená edice: Windows Server 2025 Standard Evaluation (zkušební doba 180 dní, nutno aktivovat přes internet do 10 dnů).
  • Rozhraní: První instalace s grafickým Desktop Experience, pro další role Server Core bez lokálního GUI.
  • Bezpečnostní doporučení: DHCP laboratoř musí běžet v izolovaném virtuálním přepínači, nesmí zasáhnout do produkční školní sítě.

Osvědčené postupy pro administraci

  • Před instalací role AD DS nebo jakoukoliv velkou změnou si vždy vytvořte snapshot (checkpoint) virtuálního počítače.
  • Mějte na paměti převody: Standard lze převést na Datacenter, ale zpětný převod z Datacenter na Standard není podporován.
  • U řadiče domény nelze převod z Evaluation na retail verzi provést napřímo.
