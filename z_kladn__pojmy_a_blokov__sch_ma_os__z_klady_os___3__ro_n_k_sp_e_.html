Definice a hierarchie OS

  • OS je základní programové vybavení počítače zavedené do RAM při startu.
  • Funguje jako prostředník mezi hardwarem, aplikacemi a uživatelem.
graph LR PC1[HW] --> SW[OS] --> św[UI/SW]

Dělení OS

  • Podle uživatelů a úloh: Jednouživatelský jednoúlohový (MS-DOS), jednouživatelský víceúlohový (Win XP), víceuživatelský víceúlohový (Linux, Win NT).
  • Podle typu zařízení: Desktopové, serverové, mobilní, embedded (vestavěné), distribuované.
  • Systémy reálného času (RTOS): Garantují vyřízení požadavku v pevně daném čase (QNX, VxWorks).

Klíčové funkce OS

  • Poskytování uživatelského rozhraní (CLI / GUI).
  • Správa přístupu programů k hardwaru (CPU, RAM, periferie).
  • Sledování stavu systémových prostředků.
  • Organizace souborů a správa adresářové struktury.

Vnitřní struktura systému

  • Kernel (jádro): Základní část OS v RAM zajišťující kontrolu HW a přidělování prostředků.
  • Driver (ovladač): Software umožňující OS komunikovat s konkrétním HW zařízením.
  • Userspace: Izolované prostředí pro běh uživatelských aplikací.

Procesy a vlákna

  • Proces: Instance běžícího programu s vlastní vyhrazenou pamětí a ID.
  • Vlákno (thread): „Odlehčený proces“ sdílející paměťový prostor mateřského procesu.
  • Vlákna mají vlastní zásobník (stack) a nižší režii při přepínání.

Správa času procesoru (Multitasking)

  • Kooperativní: Programy samy předávají kontrolu OS; dnes se téměř nepoužívá.
  • Preemptivní: OS plně rozhoduje o přidělování a odebírání CPU jednotlivým úlohám.
  • Změna kontextu (Context switch): Rychlé střídání procesů na CPU vyvolávající dojem paralelismu.

Klasifikace a typy OS

  • Jednouživatelské (MS-DOS) vs. Víceuživatelské (Linux, Windows NT).
  • RTOS (Real-time): Garantují odezvu v přesně daném čase (např. řízení technologií).
  • Embedded OS: Pro vestavěná zařízení jako tiskárny nebo pračky.

Historické milníky

  • 50. léta: První PC bez OS; jazyky Fortran a C.
  • 70. léta: Vznik UNIXu a první GUI u Xerox Alto.
  • 90. léta: Dominance Windows a zrození Linuxu (1991).
