Správa procesů a Volání fork() v Linuxu

Operacni Systemy

Úvod do konceptu procesů

  • Proces je běžící instance programu v operačním systému.
  • Každému procesu OS přiděluje unikátní identifikátor PID (Process ID).
  • Procesy se organizují do stromové struktury podle vztahu Rodič (PPID) -> Potomek (PID).

System Call fork() v C/C++

  • Volání fork() vnoří kompletní kopii adresního prostoru rodiče.
  • V rodiči vrací PID potomka, v potomkovi vrací 0, při chybě -1.
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>

int main() {
    printf("Zahájení hlavního procesu PID: %d\n", getpid());
    pid_t pid = fork();
    
    if (pid == 0) {
        printf("[POTOMEK] Já jsem nová větev! PID: %d, PPID: %d\n", getpid(), getppid());
    } else if (pid > 0) {
        printf("[RODIČ] Vytvořil jsem potomka s PID: %d\n", pid);
    }
    return 0;
}
